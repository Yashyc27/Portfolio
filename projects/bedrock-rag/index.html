Enterprise Knowledge Base Q&A System

A Generative AI prototype: a Streamlit app that calls Amazon Bedrock retrieval and generation, then displays the answer and returned source excerpts.

From input
to outcome.

The prototype gives a user a chat interface for querying a configured Bedrock Knowledge Base. Its source calls `retrieve_and_generate` and renders source excerpts returned by the service. A live AWS deployment was not verified.

Implementation

  • Streamlit session state stores chat messages and a query counter.
  • The app calls Bedrock Agent Runtime `retrieve_and_generate` and reads the returned answer.
  • Returned citation references are rendered with source names and text excerpts.
  • The AWS region, knowledge-base ID, and model ARN are hard-coded in the inspected source.

Limitations

  • The app was not run against a live AWS knowledge base; deployment and access control are unverified.
  • The README uses TechNova sample-company language. It is not evidence of a real client or production deployment.
  • README model details differ from the model ARN in the source; align the configuration and documentation before presenting the stack as final.
