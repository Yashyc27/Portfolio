Project notes

From input
to outcome.

Model work needs a repeatable path from data through training and evaluation to inference. This project organizes that lifecycle into an automated MLOps workflow for Yonex sentiment analysis.

Workflow

Review dataSENTIMENT
→
Prefect workflowSCHEDULED RETRAINING
→
MLflow + OptunaTRACK · TUNE
→
FastAPI on AWSPREDICTION SERVICE

Implementation

  • Prefect orchestrates the retraining workflow.
  • MLflow tracks experiments and Optuna tunes model parameters.
  • DVC versions project data and artifacts; FastAPI serves predictions on AWS.
