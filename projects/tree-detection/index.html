Tree Detection & Health Analysis

A computer-vision prototype: a Flask application that runs YOLOv7 tree detections on uploaded images and assigns crown categories using a simple color heuristic.

Reviewing aerial imagery to locate trees can take time. This prototype applies an object detector to uploaded images and returns annotated detections for inspection.

Implementation

  • Flask accepts an uploaded image; Pillow, NumPy, and OpenCV decode and prepare it.
  • PyTorch loads YOLOv7 weights and runs detection; class-0 boxes are drawn and counted.
  • Crown categories are assigned from average color thresholds; this is a heuristic, not a validated tree-health model.
  • The prototype writes output to a fixed `static/result.jpg` path; concurrent requests may overwrite one another.

Limitations

  • A compatible `.pt` model file is required; weights and measured detection results were not verified.
  • No accuracy metrics or validation of the health categories were found.
  • The README's setup instructions include placeholder repository details.
