Financial Document Management with Semantic Analysis

A work-in-progress FastAPI application for financial-document records and semantic retrieval over embedded text chunks. It does not currently generate LLM answers.

Overview

The project explores organizing financial documents and retrieving relevant text by meaning rather than relying only on exact keyword matches.

Problem & motivation

Financial material may be easier to search when a query can match related wording in indexed text. This project combines document records, text chunking, embeddings, and vector similarity search behind a REST API.

The repository describes a local development/demo application and is marked as a work in progress.

Implementation

  • FastAPI exposes endpoints for document upload, indexing, semantic search, and document records.
  • Text is split into 700-character chunks with 70-character overlap.
  • Hugging Face Sentence Transformers uses `all-MiniLM-L6-v2` to embed the chunks.
  • Qdrant performs cosine-similarity search. The current pipeline retrieves up to 20 candidates and returns the first 5.
  • SQLite and SQLAlchemy store user and document records.

Technology stack

Python · FastAPI · Uvicorn · SQLAlchemy · SQLite · Qdrant · LangChain · Hugging Face Sentence Transformers

Known limitations

  • The current system retrieves passages; LLM answer generation and semantic caching are not implemented.
  • Uploads are decoded as UTF-8 text; PDF and scanned-document extraction are not implemented.
  • The Qdrant client uses in-memory storage, so vectors do not persist across restarts.
  • The login endpoint returns a placeholder token, passwords are stored as plain text, and role checks are not enforced across document routes.
  • The document-context endpoint currently returns placeholder content rather than document-specific context.

Next steps described in the project

The repository identifies authentication hardening, persistent vector storage, document-format extraction, permission checks, document-specific context, and tests as possible next steps.
